# AgentNet v0.1.50 Setup Usability Implementation Plan

> Execute in this isolated worktree with focused tests first. Preserve every existing identity, approval, migration, and fail-closed contract.

**Goal:** One resumable server command and one resumable laptop command perform secure setup, direct supported upgrades, permanent communication activation, and an exact bidirectional setup-check within bounded time.

**Architecture:** Extend the existing CLI orchestration only. Reuse `plan_server_setup`, `apply_server_setup`, guided enrollment, C0 pilot, persistent communication scope, signed HTTP client, mailbox, and systemd services. Add no second installer or authority engine. Existing explicit commands remain forensic/automation primitives.

**Affected IDs:** ID-006, COM-001, COM-002, COM-009, AVL-003, AVL-005, AVL-006, UX-001, UX-002, SEC-003, SEC-005, OPS-003, OPS-006.
