cutover. Portable backups exclude the operator OAuth configuration. An optional
prefetch proposal was rejected by automatic approval review because it could

backup from the original data volume is planned.

`state=pending` after verifying every local ciphertext. Those expected proof
flags are not lost remote references. The migration appends only
`quota_bytes=0`; all existing rows, remote IDs, account/folder/client binding,
signed realm and non-database durable files must remain. Failure recovery must
stop and verify the candidate Hub before reading its final schema; an old image
must never be attempted against migrated data. Never restore a stale backup over
possible new writes.
