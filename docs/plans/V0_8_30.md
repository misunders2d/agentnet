## Working agreement

Root owns scope, review and release; helpers own assigned code and focused
regressions. One small shared checklist is retained at
`.agentnet/v29/live-lag/TARGET.md`, with causal evidence and failed attempts.
No new generic cache, polling, status framework or steering controls. A stored
revision is not remote delivery; native receipt is not consumption. Preserve
exact identity, attempt, topic, files and no-silent-replay fences.

Two lessons apply to this release: test the actual producer-to-UI path, not only
handmade DTOs, before claiming an everyday workflow works; measure the user
operation from click to usable result, including initial open and post-action
waits, instead of substituting unrelated fast refresh tests. Remove unnecessary
work before adding mechanisms. Use existing functions, native modes and storage.

Focused failures are batched before expensive verification. Stabilize integrated
source then run required vet, twelve600s client race partitions, UI/others,
native platforms, published-v29 mixed-version, exact-pinned all-skins, signed APK
and package qualification. Retain valid unchanged evidence. No publication or
actual ThinkPad improvement is claimed by this initial scope record.
